# 真实政策文档存放目录

请把从**山西大学官网及其职能部门公开栏目**下载的政策文件放到本目录，
然后执行：

```bash
python scripts/ingest_cli.py --dir data/raw
```

## 数据规模下限（项目要求）

- 文档 **≥ 8 份**，合计正文 **≥ 50 页**，入库文本块 **≥ 300 块**。

## 建议收集的文档类型

| # | 文档 | 建议来源栏目 |
|---|---|---|
| 1 | 本科学生选课管理办法 | 教务处 → 教学管理 / 规章制度 |
| 2 | 本科生学籍管理规定 | 教务处 → 学籍管理 |
| 3 | 毕业学分与学位授予要求（培养方案） | 教务处 / 学位办 |
| 4 | 奖助学金评定办法 | 学生工作部 → 资助管理 |
| 5 | 考试纪律与违规处理规定 | 教务处 → 考试管理 |
| 6 | 本科生转专业实施办法 | 教务处 → 学籍管理 |
| 7 | 图书馆借阅管理办法 | 图书馆 → 读者服务 |
| 8 | 学生违纪处分规定 | 学生工作部 → 规章制度 |

## 支持的文件格式

`.pdf` / `.docx` / `.txt` / `.md`

- **PDF**：需为文字版；扫描版请先做 OCR，否则解析会失败并给出明确报错。
- **DOCX**：按「标题样式」切分章节，`page` 字段记录章节名。
- **网页政策**：若某政策只以网页形式发布，可整理为 `.txt`，
  但必须在 `docs/数据来源清单.md` 中注明整理方式与原始网址。

## 重要提醒

1. 本目录的 `.pdf` / `.docx` 已被 `.gitignore` 排除（体积与版权考虑），
   如需随仓库交付，请修改根目录 `.gitignore`。
2. **禁止用 AI 编造的样例文本充当真实数据**（项目硬性要求）。
   `data/demo/` 下的文件是**明确标注的合成演示样例**，只能用于跑通链路，
   不得计入验收的数据规模，也不得写进 `docs/数据来源清单.md`。
3. 下载完成后，请逐条填写 `docs/数据来源清单.md`：文档名、来源网址、下载日期、页数。
